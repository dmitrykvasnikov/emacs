### Замечено, оставлено как есть

- `M-l` глобально — `downcase-dwim`, но внутри `corfu-map` — `corfu-show-location`. Конфликта нет (карта активна только во время всплывающего меню), но во время автодополнения `M-l` не понизит регистр.
- `C-r` глобально перекрывает `isearch-backward` (`consult-history`) — судя по всему, осознанный выбор.
- В `elpa/` установлены, но нигде не настроены: `breadcrumb`, `consult-dir`, `consult-eglot`, `haskell-ts-mode`, `treesit-fold`, `vundo`, `wgrep`, `xterm-color`, `modus-themes`, `nerd-icons*`. Либо настроить, либо удалить.
- В `elpa/` теперь не нужны совсем: `all-the-icons`, `all-the-icons-dired`, `kind-icon`, `svg-lib`, `corfu-terminal`, `popon` (см. раздел 2а). Удаляются через `M-x package-delete`.

## 2а. Унификация иконок: только nerd-icons

В конфиге было **три независимых набора иконок**. Приведены к одному:

| Место | Было | Стало |
|---|---|---|
| modeline | `all-the-icons` (не использовался: `doom-modeline` жёстко зависит от `nerd-icons` — `Package-Requires` + `(require 'nerd-icons)` в `doom-modeline-core.el:33`, то есть nerd-icons грузился при каждом старте в любом случае) | `nerd-icons` |
| dired | `all-the-icons-dired` | `nerd-icons-dired` |
| corfu | `kind-icon` | `nerd-icons-corfu` |

Почему ушёл `kind-icon`: он рисует вид кандидата (функция/переменная/класс, берётся из `:company-kind` метаданных CAPF) через `svg-lib`, а тот **скачивает SVG по сети** при первой встрече каждой иконки (`svg-lib.el:157`, `url-retrieve-synchronously` в `svg-lib.el:498`) и кэширует в `.cache/svg-lib/`. `nerd-icons-corfu` делает то же самое (`nerd-icons-corfu.el:181,186` — тот же `:company-kind`) глифами уже загруженного шрифта, без сети и без кэша, и красит их `font-lock`-фейсами, то есть следует теме.

Шрифт `Symbols Nerd Font Mono` установлен (`~/.local/share/fonts/NFM.ttf`), `M-x nerd-icons-install-fonts` не нужен.

Важно: в `corfu-margin-formatters` должен быть **ровно один** форматтер — не добавлять `kind-icon` обратно рядом с `nerd-icons-corfu`.

## 3. Новая структура

`init.el` (72 строки) теперь содержит только: имя пользователя, `load-path`, `custom-file` и список модулей.
Модули лежат в `src/`, загружаются в фиксированном порядке через `dk/load-modules` — с `condition-case`, так что один сломанный файл не рушит весь старт, а печатает сообщение и пропускается.

| Файл | Содержимое |
|---|---|
| `src/dk-vars.el` | Значения, общие для нескольких модулей: каталог auto-save, шрифт, тема, каталог org |
| `src/dk-functions.el` | Все именованные функции-помощники для хуков и команд |
| `src/dk-packages.el` | `package.el`, архивы, bootstrap `use-package` |
| `src/dk-defaults.el` | Базовое поведение редактора: бэкапы, auto-save, глобальные минорные режимы, undo, поиск, expand-region |
| `src/dk-ui.el` | Внешний вид: фрейм, прокрутка, шрифты, `doom-modeline`, иконки, `which-key`, `helpful` |
| `src/dk-completion.el` | `vertico` (+directory/multiform), `orderless`, `marginalia`, `consult`, `embark`, `corfu`, `cape`, `nerd-icons-corfu` |
| `src/dk-navigation.el` | `recentf`, `dired` (+diredfl, иконки), `projectile`, `consult-projectile` |
| `src/dk-vcs.el` | `magit`, `diff-hl` |
| `src/dk-programming.el` | Общее для всех языков: `eglot`, `xref`, `flymake`, `apheleia`, номера строк, `rainbow-delimiters` |
| `src/dk-languages.el` | Только специфика языков: LSP-серверы, `haskell-mode`, `rust-mode`/`rustic`, `go-mode`, `clang-format` |
| `src/dk-writing.el` | `markdown-mode`, `valign`, `org`, `org-modern`, `org-appear` |
| `src/dk-theme.el` | Темы; грузится предпоследним — `dk/sync-orderless` нужен уже загруженный orderless |
| `src/dk-keymap.el` | Глобальные клавиши; грузится последним, чтобы перекрывать глобальные биндинги пакетов |

`early-init.el` не тронут: там остаются GC, `package-quickstart`, отключение menu/tool-bar и функции `dk/add-to-confdir` / `dk/add-paths-to-list` — они нужны раньше, чем `src/` попадает в `load-path`.
