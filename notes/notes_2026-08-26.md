# Useful Emacs additions — 2026-08-26

`multiple-cursors` is the clearest missing editing feature. For this
configuration, I would add the following features in roughly this order.

## 1. Multiple cursors

It complements `expand-region`, Corfu, and Eglot without duplicating them. Use
it for repetitive textual edits, column-like changes, and editing selected
occurrences. For semantic code renaming, continue using `eglot-rename`.

The package supports marking next/previous/all occurrences and placing a cursor
on every selected line. See the
[multiple-cursors documentation](https://github.com/magnars/multiple-cursors.el).

```elisp
(use-package multiple-cursors
  :bind (("C->"   . mc/mark-next-like-this)
         ("C-<"   . mc/mark-previous-like-this)
         ("C-c ;" . mc/mark-all-like-this)
         ("C-c l" . mc/edit-lines)))
```

Those keys are currently unused in the configuration. Add `multiple-cursors`
to `dk/package-list`; `.mc-lists.el` is already in `.gitignore`.

Useful pattern:

1. Select a symbol.
2. Press `C->` repeatedly.
3. Type the replacement.
4. Press `C-g` to leave multiple-cursors mode.

`C->` and `C-<` may not be distinguishable in every terminal, but should work
in the GUI setup.

## 2. Writable ripgrep results with wgrep

This is probably the most powerful addition after multiple cursors. Consult
and Embark are already installed, so the workflow is:

1. Run `consult-ripgrep`.
2. Export the results with `embark-export`.
3. Enter `wgrep`.
4. Edit matches across many files as ordinary text.
5. Apply the changes.

[wgrep](https://github.com/mhayashi1120/Emacs-wgrep) writes edited grep results
back to their source files.

```elisp
(use-package wgrep
  :commands wgrep-change-to-wgrep-mode)
```

Unlike multiple cursors, this handles project-wide changes. Unlike blind
search-and-replace, each result can be inspected and edited individually.

## 3. Avy for visible navigation

Consult is excellent when searching by name or text. Avy fills the smaller
gap: “I can see the destination; move there immediately.”

[`avy-goto-char-timer`](https://github.com/abo-abo/avy) lets you type one or two
characters and then select the visible target using a short hint.

```elisp
(use-package avy
  :bind ("M-g c" . avy-goto-char-timer))
```

This replaces `goto-char` on `M-g c`, which is rarely needed interactively and
remains available through `M-x`.

## 4. Visual undo with vundo

The undo history is generously sized, but navigating branches of Emacs undo
remains difficult. Vundo visualizes the existing undo history without replacing
Emacs's undo implementation or requiring a permanent global mode. It can also
diff arbitrary undo states. See the
[vundo documentation](https://github.com/casouri/vundo).

```elisp
(use-package vundo
  :bind ("C-x u" . vundo)
  :custom
  (vundo-glyph-alist vundo-unicode-symbols))
```

Normal undo remains available through `C-/` and `C-_`.

## 5. Org capture and agenda entry points

Org's agenda directory is configured, but neither of its most useful global
workflows is exposed.

```elisp
(use-package org
  ;; existing configuration...
  :bind (("C-c a" . org-agenda)
         ("C-c c" . org-capture))
  :custom
  (org-capture-templates
   `(("t" "Task" entry
      (file ,(expand-file-name "inbox.org" dk/org-directory))
      "* TODO %?\n  %U\n")
     ("n" "Note" entry
      (file ,(expand-file-name "notes.org" dk/org-directory))
      "* %?\n  %U\n"))))
```

Capture is useful because recording something becomes independent of which
buffer or project is currently open.

## 6. Activities, if switching contexts frequently

When routinely moving between an Emacs project, another codebase, Org, and
documentation, `activities` can persist each task's tabs, windows, and buffers.
Suspending and resuming restores where the task was left, including across
Emacs restarts. See the
[GNU ELPA activities documentation](https://elpa.gnu.org/packages/activities.html).

Add this only if window-layout/context switching is an actual irritation. The
existing `winner-mode` is enough for short-lived layout changes.

## Also learn the built-in alternative to multiple cursors

Keyboard macros are often more powerful when each repetition involves movement
or a sequence of different commands:

- `F3`: start recording.
- `F4`: finish or repeat.
- `C-x C-k r`: apply the macro to every line in a region.

The latter is specifically designed for linewise repetitive transformations.
See the
[GNU Emacs keyboard macro documentation](https://www.gnu.org/software/emacs/manual/html_node/emacs/Keyboard-Macros.html).

## Recommendation

Add `multiple-cursors`, `wgrep`, `avy`, and `vundo` first. Do not add
Projectile, Company, iedit, or another formatter: they would substantially
overlap project.el, Corfu, multiple-cursors/Eglot, and Apheleia respectively.
